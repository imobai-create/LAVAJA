# Apresentação para investidor

Fonte da apresentação publicada em
<https://claude.ai/artifact/Kiav4X1ymb6kPCiLakRCae> (22 slides).

```
deck.json          índice: ordem dos slides, seções, tipografia
slides/<id>.html   um arquivo por slide, canvas fixo de 1920x1080
```

Cada slide traz as notas do apresentador em um `<aside>` no fim do arquivo.

Conteúdo em [BP-PIUMHI.md](../BP-PIUMHI.md) e [BP-REDE.md](../BP-REDE.md); os
números vêm de `docs/bp/`.
